# VIER 择偶坐标

帮用户看清三件事：**你想遇见的人是谁、他们自己在找什么样的人、谁的理想型恰好是你。** 分数只表示“条件拟合”，不是好感概率，也不是对人的价值评价。当前服务范围只包含异性恋用户。

## 运行

只需要 Node.js 18 以上，没有第三方依赖。

```bash
npm start          # 或 node server/server.mjs，然后打开 http://localhost:8787
npm run dev        # 开发用：server/、packages/、config/ 改动后自动重启；网页文件改了刷新浏览器即可
npm test           # 评分、关系引擎、接口、安全、模拟人选和统计数据的核对
```

本机默认是测试环境（`testMode: true`）：人选池是同意进入人选池的真人加上你所在城市的虚拟人选。

## 模拟人选：10 万人是怎么来的

真人用户还少的时候，结果页里的人选大部分是模拟的。模拟人选一共 **10 万人：GDP 前 100 城，每城 1000 人，男女各半**，页面上逐张标“虚拟”。他们不是随手编的，年龄、身高、学历、收入、婚姻状况都按公开统计数据校准，所以“北京的人选比周口的学历高、挣得多”这种差别是有出处的。

### 数据从哪来

| 用来定什么 | 公开数据 | 年份 |
|---|---|---|
| 每个城市的学历水平 | 第七次全国人口普查各市公报：每 10 万人中大专及以上文化程度人数（如北京 41980、上海 33872、周口 6085） | 2020 |
| 不同年龄的人学历差多少 | 《中国人口普查年鉴-2020》表 4-1：全国分年龄、性别的受教育程度 | 2020 |
| 单身的人多在哪个年龄 | 《中国人口普查年鉴-2020》表 3-1 分年龄人口、表 5-3 分年龄婚姻状况 | 2020 |
| 单身里未婚、离异、丧偶各占多少 | 《中国人口普查年鉴-2020》表 5-3，分年龄、性别 | 2020 |
| 每个城市的收入水平 | 各市 2023 年统计公报：城镇常住居民人均可支配收入、城镇非私营单位平均工资 | 2023 |
| 身高 | 《中国居民营养与慢性病状况报告（2020年）》：18–44 岁男性平均 169.7 cm，女性 158.0 cm | 2020 |

原始数字都在 `config/stats/`，每个数字带来源链接；100 城逐城明细见 [docs/DATA.md](docs/DATA.md)。

### 每个人是怎么生成的

每座城市用城市编号当随机种子，所以同一座城市每次生成的 1000 人完全一样。每个人按下面的顺序抽：

1. **性别**：前 500 个女生，后 500 个男生。
2. **年龄（22–45 岁）**：按全国“各年龄段人口 × 没结婚的比例”抽，也就是单身的人在哪个年龄多，就多抽哪个年龄。结果是男生 25–29 岁最多（约 34%），女生 22–24 岁最多（约 36%），40–45 岁合计约 8%。
3. **身高**：按报告的平均身高取正态分布，男生标准差 6.2 cm、女生 5.6 cm，男生限 155–198、女生限 145–185。
4. **学历**：先查这个城市七普的大专及以上比例。这是全年龄口径，年轻人学历更高，所以按全国“这个年龄段比全年龄高出多少”往上换算。比如周口全年龄只有 6%，换到 27 岁的人身上约 18%（男）到 22%（女）。大专以上再按全国该年龄段的构成分成大专、本科、硕士、博士；城市学历越高，本科和硕博占得越多。
5. **收入**：
   - 先定城市目标：城镇人均可支配收入 × 2.0 × 0.8。乘 2.0 是因为人均收入把老人小孩也算进去了，换成上班的人要翻倍左右（42 个两项数据都有的城市，工资大约是人均可支配收入的 2 倍）；乘 0.8 是因为公布的工资只算国企、事业单位这类非私营单位，私营单位低一些。
   - 再给每个人一个基础值，按学历加减（硕士比本科高约 30%，高中及以下比本科低约 35%），按年龄加一点（工作满 12 年左右涨到头），女生略低。
   - 最后整体缩放，让这座城市 1000 人的平均收入正好等于目标。
6. **婚姻状况**：按七普同年龄、同性别的单身人里未婚、离异、丧偶的比例抽。比如 38 岁的单身男生，约 68% 未婚、31% 离异；38 岁的单身女生，约 51% 未婚、44% 离异。离异的人里，一半有孩子。
7. **其他资料和择偶要求**：住房、车、个人和父母的家底、职业、性格、生活方式、结婚和生育打算，以及所有择偶要求（年龄范围、身高、最低收入、学历等），按经验比例抽，没有逐项对应统计数据。例如年收入 15 万以上的人约 65% 有车，以下约 40%；女生多找同龄或大几岁、比自己高 3–12 cm 的，男生多找同龄或小几岁的。

### 生成出来是什么样

| 城市 | 大专及以上 | 本科及以上 | 年收入中位数 | 年收入平均 |
|---|---|---|---|---|
| 北京 | 71% | 47% | 11.8 万 | 14.2 万 |
| 上海 | 62% | 38% | 11.8 万 | 14.3 万 |
| 杭州 | 57% | 35% | 10.4 万 | 12.9 万 |
| 洛阳 | 32% | 18% | 5.9 万 | 7.3 万 |
| 周口 | 21% | 8% | 4.5 万 | 5.3 万 |

各城平均年龄都在 29 岁左右，单身人里未婚约 86–88%。

### 缺数据怎么办

22 个城市没查到 2023 年可支配收入（如大连、沈阳、厦门、昆明、哈尔滨），乌鲁木齐没有市级学历数据，都用同档城市（`config/cities.json` 的 `tier`）的中位数补，在 docs/DATA.md 的明细表里标“估算”。

### 怎么查看、怎么改

- **不用单独生成**：服务器启动后第一次用到某个城市时，在内存里生成并缓存，部署时不需要额外步骤。
- **导出看看**：`node scripts/export-sim-pool.mjs` 写出 `data/sim-export/全部人选.csv`（10 万行）和 `城市汇总.csv`，Excel 直接打开。
- **自动核对**：`npm test` 会把 100 城都生成一遍，检查每城平均收入等于目标、大专以上比例落在期望值的抽样误差内、身高和婚姻状况与全国数据一致。
- **改规则**：数字和换算在 `server/src/sim-calibration.js`，抽样顺序在 `server/src/sim-generate.js`；要换新一年的数据，改 `config/stats/` 里对应的数字即可。

## 部署上线

上线用的是正式配置（`config/app.production.json`）：虚拟人选在卡片上标“虚拟”。备案号填在 `site.icp`，页脚自动显示。

**准备**：一台装好 Docker 的服务器，一个已解析到这台服务器的域名（大陆服务器需 ICP 备案）。

```bash
git clone <仓库地址> vier && cd vier
cp .env.example .env
docker compose up -d
```

第二步之后编辑 `.env`：`DOMAIN` 是你的域名，`VIER_DATA_KEY` 用 `openssl rand -base64 32` 生成，`ADMIN_TOKEN` 是后台口令。

打开 `https://你的域名` 就能用。HTTPS 证书由 Caddy 自动申请和续期；不活跃满一年的账户由服务每天自动清理。

**密钥**：另存一份，和备份分开放。**密钥丢了或换了，所有资料都打不开。** 没填密钥时，服务拒绝启动。

**更新**：`git pull && docker compose up -d --build`，用户数据不受影响。

**备份**：资料在 Docker 数据卷里，每天拷一份出来（拷出的是加密后的文件）：

```bash
docker compose cp app:/data ./backup-$(date +%F)
```

**看日志**：`docker compose logs -f app`

**现在的限制**：限流计数在内存里，只适合单进程；文件存储只适合试点规模；用户协议和隐私政策是大白话初稿，上线前请懂法的人看一遍。

## 目录

| 路径 | 内容 |
|---|---|
| `web/` | 新网页前端（关于你 → 理想型 → 同意 → 结果 → 人选详情 → 我的数据，每步独立页面） |
| `server/` | HTTP 服务、加密存储、同意、导出、删除、审计、对外展示的脱敏层、凭号进入 |
| `packages/schema/` | 字段注册表：资料、要求、评分、隐私分级共用的唯一来源 |
| `packages/scoring/` | **可替换的评分模块**（当前 `fit-v1`），只通过接口被调用 |
| `packages/matching/` | 关系引擎：理想型人选、对方的理想型、你符合对方理想型的程度、在找你的人、双向相合 |
| `config/app.json` | 演示配置：人选池、每组人数、评分器、隐私参数 |
| `config/app.production.json` | 正式上线配置：`testMode: false`，其余同上 |
| `config/cities.json`、`config/stats/` | 100 城列表；模拟人选用到的公开统计数据（带来源） |
| `scripts/` | 导出模拟人选、清理长期不活跃账户 |
| `docs/` | 架构、命名、评分、隐私、决策记录 |
| `archive/2026-11-15-pure-web/` | 旧的纯网页版本、模拟库、宣传图与研究资料，原样保留 |
| `data/` | 本机运行时数据（不进 git） |
| `Dockerfile`、`docker-compose.yml` | 部署：一条命令启动服务和 HTTPS |
