# VIER 上海 500 人模拟档案库

直接用浏览器打开 `index.html`。页面内嵌全部数据，无网络依赖；可搜索、多条件筛选、排序、分页、查看完整个人及家庭档案、查看底部按字段分组的 51 张动态分布图、导出当前筛选 JSON/CSV，以及查看可点击的 Z 字关系图。

## 文件

- `profiles.json`：带元数据的完整结构化数据，权威数据源。
- `profiles.csv`：UTF-8 BOM，500 行；family、preferences、incomeRecord、sections、thirdPartyAdvice、fieldEvidence 为 JSON 字符串，seeks 以竖线分隔。
- `index.html`：自包含浏览页，支持手机与电脑布局。
- `generate.mjs` + `template.html`：生成器与页面模板。在本目录运行 `node generate.mjs` 可用固定种子复现全部产物（会覆盖本目录的生成文件）。Node 18+，无第三方依赖。
- `validation.json`：数量、编号、年龄、收入与示例三条边的逐项检查。
- `interaction-checks.json`：记录生成器的分箱计数检查。

## 模拟口径与边界

生成日期 2026-11-13，种子 20261113；500 人均设定上海、单身、22–39 岁、已生活至少 6 个月。编号与中性数字头像均为虚构，没有姓名、具体住址、亲属单位、联系方式或真实社交平台资料。未采集小红书、抖音或任何真实用户。

性别为女 250、男 250；全部档案标为异性恋，女性寻找男性、男性寻找女性。这是便于演示的均衡造数配置，不代表现实性别、取向或择偶偏好占比。年龄、身高、职业、学历、收入及家庭字段多数字段独立抽取。净资产按住房等字段的人工权重分档，尚未模拟真实社会的联合关联，不能据此研究群体差异。性别或取向不参与收入生成或价值评价。产品当前服务范围仅设为异性恋用户。

年收入为最近12个月税前个人劳动收入，含奖金和兼职，不含投资、房产与家庭转移。生成抽取概率：10% 为3–7万、68% 为8–20万、18% 为21–35万、4% 为36–65万，各段按整万元均匀抽取。有限样本实际比例会波动。当前实际中位数16万、均值17.476万、超过35万22人。没有百万元年收入。资产以人工分档展示，没有精确估值。分布仅为普通收入优先的人工校准，不是统计拟合。

参考背景已核查：上海2025全口径城镇单位就业人员平均工资12,577元/月；上海2025全体居民人均可支配收入91,987元；全国2025城镇私营/非私营单位年平均工资71,590/129,441元。就业工资与居民可支配收入的统计对象、口径不同，均不等于上海适婚单身人口收入分布，不可直接套用。来源链接见页面。

500 人可用于字段和粗粒度描述演示，不能代表上海全部单身人群；真实研究每城2,000–3,000人只是下一轮细分探索的预算起点，不保证准确性。

## 规则和 Z 字图

单向 `evaluate(目标, 提出期待者)`：目标性别须在提出期待者的 seeks 范围，且通过其明确收入硬门槛。通过后计算年龄、身高、收入、学历、住房、定居、家庭支持、婚姻、育儿、性格、生活方式11项二元重合，按期待者1–3权重加权：`四舍五入(100 × 重合项权重和 / 全部项权重和)`。不代表心理吸引、好感或真实相处。

Z 图方向为 B→A、C→B、D→C，即 A 是 B 的理想型、B 是 C 的理想型、C 是 D 的理想型。程序依编号扫描 C，再依规则分及编号顺序寻找 A/B，寻找互不重复且三条边均100规则分的示例。固定全库示例不随筛选变化。刻意选取完整覆盖路径只为解释方向，不能据此声称100%命中。其他路径可出现冲突或不存在，不补造档案。
