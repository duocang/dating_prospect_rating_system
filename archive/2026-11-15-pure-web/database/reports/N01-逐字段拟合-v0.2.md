# VIER 逐字段拟合方案 v0.2

2026-11-13。供数据库与网站实现讨论。当前参数为产品试算，待真人校准。现有演示页继续使用原先的二元条件重合规则。

## 输入与方向

设 F(档案, 要求) 为单向拟合。B 是 C′ 填写的目标，计算 F(B′, B)。选定 B′ 后，以其本人填写的要求形成 A，再计算 F(A′, A)。每位 D′ 有自己的要求，计算 F(C′, D′ 的要求)，用来描述概念 D 的候选。C′ 是具体客户。不同 B′ 下的 A 应各自列出。D′ 的评分分母、权重可能不同，按其自述要求的满足比例比较时，必须同时展示要求数、领域覆盖和门槛，避免把「要求很少」误读为「更喜欢 C′」。

每项要求保存提出人、字段、单位/版本、比较方式（至少、至多、约、范围、类别、时间可行性）、目标、必须或软偏好、权重组及组内权重。档案字段保存原值或区间、口径、资料状态和日期。没有偏好与缺失值分别处理。每条结果保存档案值、目标、规则版本、单项结果、权重、区间和理由，供网站复算。

## 函数

- **金额软下限。** 目标 t>0 时，R(x,t)=100×min(1,max(0,x)/t)。税前年劳动收入 9 万对目标 10 万为 90 分。超过目标封顶 100 是建议。零目标且表示无最低要求时停用该项，明确「净资产非负」用阈值规则。对目标为负、目标为精确值或上限的金额要求，使用距离规则。零收入与未披露分别处理。
- **数值距离。** 约 t 用 |x−t|，至少 t 用 max(0,t−x)，至多 t 用 max(0,x−t)，理想区间 [L,U] 用 max(0,L−x,x−U)。软分 G=100×max(0,1−距离/尺度)。身高目标 180、实际 170，相差 10 cm，尺度 10/20/30 cm 分别为 0/50/66.7。年龄同形但尺度用年。若问卷给出「理想区间」和「最远仍可协商点」，分别按两侧距离设定尺度，可表达非对称。备选分段线性可按本人给出的中间锚点插值。
- **类别。** 用户明确的理想类别得 100，普通接受集合可直接得 100。若明确区分理想与可接受，可接受类别试用 60，其他为 0。无法确定类别或口径时标未知。明确不能接受的情况可以配置独立门槛。
- **多选。** 目标标签的命中权重 ÷ 所有目标标签权重 ×100。额外兴趣不扣分。排除项单列。只有在信息确认为完整时，未选中的目标标签才记未命中。全部、任一和可同时实现三种要求分别表达。
- **区间。** 对档案可能值集合求评分最小值和最大值。金额单调时取端点，非单调距离还须检查区间内部是否包含理想点或与理想区间重叠。10 万收入软下限对 8–12 万档案为 [80,100]。净资产目标至少 100 万对 50–100 万档案为 [50,100]，若右端开区间则 100 是上界。金额区间语义不清时先修正口径。对日期和可协商计划，双方明确可选时段重叠可记达标，候选日期只是未知范围时用区间上下界。

## 字段选择

| 字段 | 函数与口径 |
|---|---|
| 年龄、身高、体重 | 分别用岁、cm、kg 的距离，支持单点、范围、至少与至多。体型类别用用户集合，避免和体重重复计权。 |
| 年收入 | 同币种、期间、税前税后及劳动收入口径，用 R。工资、家庭供给和预期收入分别保存。 |
| 学历 | 已取得学历按明确下限达标，低于下限默认 0。阶段和在读另按集合。 |
| 职业、行业、就业状态 | 类别集合。工时、收入波动按本人明确容忍范围另算。 |
| 常住地、户籍、成长地、定居 | 独立类别。城市居住时长用月数距离。未来迁居日期用时间差，长期计划可行性单列。 |
| 本人住房、父母住房 | 产权、现住安排、房贷、购房计划拆开用类别。住房净值和资产同组控制权重。 |
| 个人与父母家庭净资产、存款 | 分别定义主体及债务扣除，正金额下限用 R，分档保留界限，负净资产保留负值信息。相互包含的指标用组内替代或限权。 |
| 家庭经济支持、债务 | 支持意愿与可支配金额分开，分别用类别与 R。偿付压力用比例上限距离，债务类型用集合。 |
| 父母婚姻、养老医保、手足、照护 | 父母婚姻及保障类型用自选类别，手足人数、照护工时及支出可用距离。明确未披露时给未知。 |
| 婚恋状态、已有子女、婚姻计划、育儿 | 分别设类别、人数或时间范围。硬性婚育冲突独立筛除。「未决定」按填写者认可的集合比较。 |
| 沟通、冲突处理、作息、兴趣、宠物 | 具体行为或可接受集合，作息可比较可相处的时段，兴趣按标签覆盖。 |
| 吸烟、饮酒 | 吸烟状态按类别，饮酒可用频次或用量区间，两项分别处理。 |
| 外貌自评、照片、自由文本 | 自评和照片供本人判断。文字提取的结构化条件须确认后才使用。 |
| 留学、学业和跨地域 | 地区及阶段用集合，毕业日期用时间距离，异地用时长和结束安排，语言用可沟通语言交集与明确水平门槛。 |
| 性别范围、资格和核验 | 性别等范围先筛。身份核验、证据状态、提交版本、资格分别展示，不加拟合分。 |

## 权重、缺失和排序

设领域权重为 W，领域内按用户给出的相对重要度分配。首版可用 1/2/3 作为问卷表达，组间权重由用户分配或确认，空领域去除后对其余领域归一。所有有效软项权重 w 加总为 1，同一概念的每位候选使用同一组权重。相近字段同组，相关条件过多时要求用户选择主条件或分享固定组权重。只有硬门槛而无软项时，只报告是否满足门槛。

门槛判定看整个可能值集合：全部满足为通过，全部违反为失败，横跨阈值或资料未知为待核实。例如严格收入 ≥10 万，8–12 万为待核实。失败与待核实均退出正式排序池。某项兼有明确硬底线和更高的软目标时保存两条规则。正式通过资格与来源核对按产品审核流程执行，得分与资料状态分别展示。

每个软项确定分 s 等价于 [s,s]。候选未披露或口径冲突时保留 [0,100] 的可行分，标为未知。总分界限是各项上下界的固定权重和。另报有界资料的权重占比和精确资料占比，有界资料包括有效分档。有界比例阈值可先试 80%，属产品参数。示例若收入权重 30% 且未知，其余项都 100，显示范围 [70,100]、覆盖率 70%，不会因为已知项均 100 而进入正式榜。区间是可行边界，不代表概率区间，可能因字段关联而偏宽。

前五名先看门槛、覆盖率，再取相对接近者。区间可以用下界作稳定展示顺序，同时标明确定领先仅发生在某人的下界高于另一人的上界。对每人计算名次范围：最好名次 = 1 + 下界严格大于其上界的人数，最差名次 = 候选人数 − 上界严格低于其下界的人数。并列或区间跨过第 5 位时标记边界候选，显示可替换者；固定版面可用编号决定同分展示顺序。少于五人时显示实际数量和原因。D′ 还需对比每份要求表的覆盖领域数及严格程度，优先展示可比较的要求，保留逐项解释。

## 可复算的前五名

演示 B′ 榜。C′ 的硬条件为候选愿在上海长期定居、双方性别方向符合当前范围、候选明确希望育儿。软条件依次为收入至少 10 万、身高约 180 cm、年龄 28–32、本科及以上、整租或自有住房、直接沟通。权重依次 30/20/15/15/10/10。身高尺度 20 cm，年龄尺度 5 年，住房和沟通按 100/0。下表全部为虚构，未写不同项均达标且硬条件通过。

## 参数出处与验证计划

收入比例源于用户定义。身高 10/20/30 cm、年龄 5 年、类别 60、覆盖率 80% 及权重情景用于敏感性试算。默认优先让用户确认可协商边界。用模拟档案检查单调性、开闭区间、缺失、硬门槛、分数上下界、同分及结果复现。用获授权的真人档案评价另行比较曲线和权重，按评价者隔离训练与留出，限制同一档案跨分组泄漏。分别观察软条件评价一致性、前五稳定性、硬门槛冲突率、覆盖及缺失偏差。具体互动和约会结果需要独立观察。

Akehurst 等的线上约会研究分别使用画像及交互信息，为区分方向与数据类型提供背景。Joel 等在两组速配研究中未能凭见面前的量表预测两人特有的初始吸引，支持把本报告的分数解释为条件拟合。两项研究均未提供这里的字段扣分尺度。[IJCAI 论文](https://ijcai.org/proceedings/2011/367) · [Joel 等，2017](https://pubmed.ncbi.nlm.nih.gov/28853645/)
