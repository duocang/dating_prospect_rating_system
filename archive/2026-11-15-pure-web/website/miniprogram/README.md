# VIER 手机小程序原型

这是一个原生微信小程序前端原型，按单机演示制作，未接入账号、真实用户数据库、支付、实名认证或分红系统。人物、头像插画与拟合值均为虚构示例。

## 页面

- `pages/home/index`：手机端 Z 字关系总览；A、B、D 打开各自的五份示例档案，C 打开本机资料表。
- `pages/candidates/index`：查看五份示例档案及演示拟合值。
- `pages/person/index`：查看完整人物介绍。
- `pages/compare/index`：分开查看 C-A 和 B-D 的条件对照。
- `pages/profile/index`：体验本机资料编辑，数据仅写入当前设备本地缓存。

## 在电脑上预览

1. 安装并打开微信开发者工具。
2. 选择“导入项目”，项目目录选择本文件夹。
3. 使用体验项目配置运行模拟器。当前 `appid` 使用 `touristappid` 作为本地演示占位；手机微信扫码预览、上传或发布需要正式的小程序 AppID、开发者工具账号和对应成员权限。

正式发布还需补齐产品主体、隐私说明、用户授权、数据安全、服务域名以及平台审核。当前目录中的 `preview.html` 是手机浏览器预览入口，不等同于已发布的小程序。
