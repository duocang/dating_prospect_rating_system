# 默认在意程度（权重）

用户说不清每条要求有多重要，所以选好条件时，先预填一个默认的在意程度，用户随时可以改。

## 现在
- 只用 4 档：有最好 / 在意 / 很在意 / 必须有，对应打分权重 1 / 2 / 3 / 门槛（见 `packages/scoring/src/v1/scorer.js`）。不给连续百分比。
- 默认值在 `web/app.js` 的 `DEFAULT_IMP`，按“找男生 / 找女生”分开，是参考公开婚恋调查里各项大致排序给出的起点。
- 要求确认页用横条显示各条在打分里的占比；“必须有”单独列出，不参与比例。

## 以后
1. 同意参与统计的用户够多（每组至少几百人）后，按性别、年龄段、城市分组，取各条“在意程度”的平均，替换 `DEFAULT_IMP`。由服务端汇总，只出分组平均，不出个人数据。
2. 想让个人权重更准：给用户看几组“两位人选选一位”，从选择反推权重（成对比较）。比拖滑块更可靠。
3. 不用社交平台抓取的数据：有平台规则和版权风险，发帖人群也偏，代表不了一般用户。
