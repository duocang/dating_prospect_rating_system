# 限流与账户安全

| 什么 | 上限 | 按什么计 |
|---|---|---|
| 发验证码 | 每小时 10 次；同一号码每天 5 次；同一号码 60 秒 1 次 | IP / 号码 |
| 验证登录 | 每小时 30 次；同一个验证码错 5 次作废 | IP |
| 开新会话 | 每小时 30 次 | IP |
| 看结果 | 每小时 60 次（防止反复改要求扫描人选池） | 账户 |
| 保存资料、要求等 | 每小时 300 次 | 账户 |
| 后台口令输错 | 每小时 10 次，之后锁 1 小时 | IP |

上限可在 config 的 `rateLimits` 里改，格式 `[次数, 毫秒]`。部署在 Caddy 后面时 `TRUST_PROXY=1`（docker-compose 已设好），从 X-Forwarded-For 取真实 IP。计数在内存里，重启清零，多进程时要换成 Redis。

- 验证码用加密安全的随机数；过期的定时清掉。
- 令牌 90 天不用就失效（`privacy.tokenTtlDays`）。
- 一题没填、也没登录的空账户 7 天后删除（`privacy.emptyRetentionDays`）。
- 登录时，如果这台手机上刚填了资料、号码又已有一份，先问用户留哪份。
- 同意时必须勾选“已满 18 岁”。
- 网页禁止被别的网站套进框里（frame-ancestors 'none'）。
- `/api/health` 用于监控。
