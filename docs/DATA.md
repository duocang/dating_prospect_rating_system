# 模拟人选：数据来源与方法

VIER 的模拟人选覆盖 GDP 前 100 城，每城 1000 人（男女各半），共 10 万人。年龄、身高、学历、收入、婚姻状况按下面的公开统计数据校准；其他字段是建模假设，逐条写在后面。模拟人选不是真人，页面上逐张标注。

原始数据在 `config/stats/`（每个数字带来源链接和年份），换算在 `server/src/sim-calibration.js`，生成在 `server/src/sim-generate.js`，核对在 `server/test/sim.test.mjs`（每次 `npm test` 都跑：100 城逐一检查收入均值和学历比例）。

## 一句话（对外宣传用）

> VIER 的 10 万人模拟样本，按第七次全国人口普查、各城市 2023 年统计公报、《中国居民营养与慢性病状况报告（2020年）》等公开数据校准，覆盖 GDP 前 100 城，每城 1000 人；学历、收入、年龄、身高、婚姻状况的分布与公开统计口径一致。

能说的：分布按公开数据校准。不能说的：真实用户、真实数据、“和某城真实单身人群一模一样”。字段之间的关系（比如学历越高收入越高）部分是建模假设。

## 方法

1. **年龄**：22–45 岁。各年龄段的权重 = 该年龄段人口 × 非有配偶比例（全国，分性别），即“单身的人多在哪个年龄”。
2. **婚姻状况**：在单身的人里，按该年龄段、性别的未婚 / 离婚 / 丧偶比例抽。
3. **身高**：正态分布，均值取报告值；报告未公开标准差，取男 6.2 cm、女 5.6 cm（建模假设）。
4. **学历**：城市大专及以上比例是全年龄口径。按全国“该年龄段、性别 vs 全年龄”的对数几率差，把城市比例换算到每个人的年龄、性别。大专以上内部（大专 / 本科 / 硕士 / 博士）按全国该年龄段构成；城市学历越高，本科份额乘 (城市比例 / 全国比例)^0.5、硕博乘 (城市比例 / 全国比例)（建模假设）。
5. **收入**：城市目标 = 人均可支配收入 × 2.0 × 0.8。2.0 是同时有两项数据的 42 城里“非私营单位平均工资 / 人均可支配收入”的中位数，把人均口径换成在业者口径；0.8 折算私营单位工资较低（建模假设）。只有工资没有可支配收入的城市，目标 = 工资 × 0.8。个人收入取对数正态分布（σ = 0.6，建模假设），学历、年龄、性别带来差别（建模假设），最后整体缩放，让全城平均正好等于目标。
6. **缺数据的城市**：用同档城市（`config/cities.json` 的 tier）的中位数补，下表标“估算”。

## 建模假设（不是统计数据）

职业、住房、个人和父母家底、家庭支持、父母养老、兄弟姐妹、照护、父母婚姻、车、其他负债、定居、结婚和生育打算、性格、生活方式、对长相的要求，以及所有择偶要求，按经验比例抽取，没有逐项对应公开数据。央行 2019 年调查的家庭平均净资产（289 万元）被少数高资产家庭拉高，也是家庭而非年轻单身个人口径，所以没有直接用。
