# 账户与恢复码

没有手机号、没有密码。打开网页就开一个匿名账户，令牌存在浏览器里（`localStorage` 的 `vier.token`）。

- 不用登录也能填写资料、看结果。
- 换手机或清了浏览器，令牌就没了。想找回，要先在旧设备上生成一个**恢复码**。
- 恢复码 12 位，显示成 `XXXX-XXXX-XXXX`，去掉了 0/O、1/I/L 这些容易看错的字符；输入时不分大小写，横线和空格可有可无。
- 明文只在生成时显示一次。再生成一次，旧码立即作废。
- 在新设备上输入恢复码：服务端发新令牌，旧设备上的令牌失效；新设备上刚开的匿名会话不保留。

## 入口

- 首页（已开始填写后）：“存个恢复码，换手机也能找回” / “重新生成恢复码”；点“换个人，从头开始”时，没存过恢复码会先提示存一个。
- 最后一步（`#/consent`）：“换手机也想找回？”。
- 我的资料（`#/privacy`）：“恢复码”和“用恢复码找回”。
- 找回页：`#/recover`（首页“已经填过？用恢复码找回”）。

## 存储

- `data/recovery-index.json`：带密钥的 HMAC（`recovery:` + 规范化后的码）→ 用户 id，不存明文。
- 身份库里只记一个标记 `recovery: true`，用于界面提示和“空账户清理”时不删存过恢复码的账户。
- 删除账户时，索引里的那一条一起删掉。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/me/recovery` | 需令牌。生成新恢复码，返回 `201 { code }`；旧码作废 |
| POST | `/api/recover` | 不需令牌。`{ code }` → `200 { token }`；码不对返回 `400`；按 IP 每小时 10 次 |

`GET /api/me` 里的 `hasRecovery` 表示是否生成过恢复码。
