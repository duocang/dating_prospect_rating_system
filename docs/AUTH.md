# 登录

没有密码，只用**手机号 + 短信验证码**。

- 不登录也能填写资料、看结果（匿名会话，令牌存在浏览器里）。
- **牵线必须登录**：请求和回复可能要过几天，登录后换手机、换浏览器都能回来。
- 登录时如果这个号码还没有账户，就绑定到当前的匿名会话；如果已有账户，就切换到那个账户（换设备找回），旧设备上的令牌失效。
- 登录的号码会作为默认联系方式，之后可以在“牵线”里改成微信号或删除。

## 存储

- `data/phone-index.json`：带密钥的哈希 → 用户 id，不存明文号码。
- 号码本身存在加密的身份库 `data/vault/<id>.json`。
- 验证码只存在内存里：5 分钟有效，60 秒内不能重发，错 5 次作废。

## 测试与上线

- 测试环境（`testMode: true`）不发短信，验证码直接显示在页面上，并打印在终端。
- 正式环境需要接短信服务（阿里云或腾讯云短信），接好之前 `/api/auth/code` 返回 503。

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/auth/code` | 发验证码 `{ phone }` |
| POST | `/api/auth/verify` | 验证并登录 `{ phone, code }`，可能返回新令牌 |
