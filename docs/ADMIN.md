# 管理后台

地址：`/#/admin`。口令是服务器环境变量 `ADMIN_TOKEN`；测试环境（`testMode: true`）没设时为 `admin`，正式环境不设就进不去。口令用随机长串，例如 `ADMIN_TOKEN="$(openssl rand -base64 24)"`。同一 IP 一小时内错 10 次锁一小时，每次失败记 `admin.auth_failed`。登录后口令存在浏览器 localStorage，点“退出”清除，不要在公用电脑上登录。

## 能做什么

- **表格总览**：全部真人，加上一个城市的虚构人选（标“虚构”，城市可切换）。“简洁”只列名字、微信号、来源、性别、年龄、城市、职业、要求条数、活跃时间；“详细”列出微信号和全部资料字段。可按名字、城市、职业、id 搜索，按来源筛选。一次显示 200 位，可继续加载。
- **查看全部资料**（点名字或 id）：星空关系（星图，以及 B 理想型、D 想找 TA 的人、A 理想型的理想型三份名单，和 TA 自己看到的结果同样计算），加上一个人的所有资料字段和对另一半的所有要求（连同在意程度），按组列出，没填的显示“未填写”；金额显示具体数字，不分档。查看真人记 `admin.user_viewed`。
- **删除**：永久删除资料、要求、恢复码，必须写理由，审计日志记录 `admin.user_deleted`。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/admin/overview?city=<城市>` | 真人 + 该城虚构人选，带全部字段 |
| GET | `/api/admin/users/<id>` | 单个人（真人或虚构 id）的全部资料、要求和星空关系 |
| DELETE | `/api/admin/users/<id>` | 删除 `{ reason }` |

所有请求带请求头 `x-admin-token`。
